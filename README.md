# 📊 Data Analytics & SQL Portfolio

Welcome to my central project repository! This space contains end-to-end data processing workflows, analytical queries, and dataset transformation scripts demonstrating practical data engineering and SQL techniques.

## 📂 Repository Structure

* **`COVID Analysis/`** — Exploratory data analysis (EDA) queries focusing on global vaccination rates, death percentages, and population metrics using joins and CTEs.
