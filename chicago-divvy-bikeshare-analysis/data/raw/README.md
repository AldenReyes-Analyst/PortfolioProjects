# 📂 Raw Data Source

## 📌 Dataset Overview
This folder references the raw, uncleaned bike trip datasets used in this analysis. The dataset covers **12 consecutive months** of Divvy bike-share data in Chicago:

* **Timeframe:** September 2025 to August 2026 (`202509-divvy-tripdata` through `202608-divvy-tripdata`)
* **Data Provider:** Motivate International Inc. / Divvy (City of Chicago)
* **License:** Released under the [Divvy Data License Agreement](https://divvybikes.com/data-license-agreement)

---
