## 📌 Dashboard Overview
The Tableau dashboard translates SQL aggregations into actionable visual insights designed to help executive stakeholders understand rider behaviors and convert **casual riders** into long-term **annual members**.

### Key Visualizations Included:
1. **Total Trips & Average Duration:** Comparison of overall ride counts and trip lengths between members and casual riders.
2. **Weekly & Seasonal Ride Patterns:** Line and bar charts showing peak usage across days of the week and months (`yyyy-MM`).
3. **Hourly Peak Traffic:** Heatmap / area chart breaking down ride start times throughout the 24-hour day.
4. **Bike Type Preference:** Proportional split of Classic vs. Electric bikes across rider types.
5. **Top Start Stations:** Map and ranking of highest-traffic starting stations among casual riders to guide targeted marketing placement.
